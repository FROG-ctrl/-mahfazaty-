# محفظتي 💰

تطبيق فلاتر لإدارة فلوسك اليومية: مصاريف ودخل، سلف ودين، وجمعيات — كله بشكل عربي RTL ومصقول.

## المميزات

- **لوحة رئيسية**: الرصيد الحالي، دخل ومصروف الشهر، رسم بياني لمصاريف آخر ٧ أيام، وآخر العمليات.
- **عمليات مخصصة بالكامل**: التصنيف بيكتبه المستخدم بنفسه (زي "علاج برد" أو "مصاريف مستشفى")، من غير اقتراحات جاهزة — والتطبيق بيتعلم من تسمياتك ويقترحها عليك بعد كده.
- **سلف ودين 🤝**: تبويبين "لي" و"عليا"، إجمالي كل جهة والصافي، تسديد بضغطة، وسجل للمسدد.
- **جمعيات 📅**: اسم الجمعية، القسط الشهري، عدد الشهور، شهر البداية، ودورك في القبض. التطبيق بيحسب إجمالي اللي هتقبضه وإمتى، وشبكة شهور تفاعلية تعلم فيها على كل قسط دفعته.
- **إحصائيات 📊**: دونات توزيع المصاريف حسب التصنيف + مقارنة الدخل بالمصروف آخر ٦ شهور.
- **أنيميشن Lottie**: سبلاش متحرك، حالات فارغة متحركة، وتأكيد نجاح متحرك عند أي إضافة.
- خط Cairo مدمج، ثيم أخضر زمردي وذهبي، وتخزين محلي كامل (SharedPreferences) — مفيش حسابات ولا سيرفرات.

## التشغيل

```bash
flutter pub get
flutter run
```

## هيكل الكود

```
lib/
├── main.dart            # نقطة البداية + الثيم والترجمة
├── models.dart          # WalletTx / Debt / Jam3eya + JSON
├── store.dart           # WalletStore (ChangeNotifier + حفظ محلي)
├── theme.dart           # الألوان والثيم
├── utils.dart           # تنسيق الفلوس والتواريخ بالعربي
├── screens/             # splash / home / debts / jam3eyat / stats
└── widgets/             # charts (رسوم مخصصة) + empty states + success overlay
```
